# RESTful Task API
A lightweight backend PHP API endpoint designed to handle HTTP GET and POST requests for a task management system.

## Features
* **RESTful Architecture**: Implements standard HTTP methods (GET for retrieval, POST for creation).
* **JSON Responses**: Structures data responses using JSON to simulate seamless database interactions.
* **CORS Configured**: Headers are set up to allow frontend applications to consume the API.

## How to Run
1. Place the `api.php` file in the root directory of a local PHP server (e.g., XAMPP, Laragon).
2. Start your Apache server.
3. Access `http://localhost/api.php` via browser or Postman to test the GET request.
